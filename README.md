# Magic 8 Ball

An extremely scientific console oracle for the modern age.

Ask it a question, press Enter, and receive a prophecy delivered by a very confident circle.

## What It Does

- Quietly patiently listens to your silly questions.
- Answers any and all questions and even predicts the future.
- Multitudes of levels more intelligent than AI  ...and cheaper too!
- Lets you leave politely with `quit` or `exit`  ...Sometimes.

## How To Run

```bash
dotnet run
```

## Example Questions

- Will I become rich before lunch?
- Is this a binary question?
- Should I trust the vibes?
- Where are my socks?

## What To Expect

Sometimes the ball is wise. Sometimes it is theatrical. Occasionally it is rude.

Either way, it is never boring.

## Project Notes

- Target framework: `net10.0`
- App type: console application
- Main attraction: unnecessary confidence
